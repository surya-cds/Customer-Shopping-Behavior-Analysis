# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using Python, SQL, PostgreSQL, and Power BI.

## Objectives

- Analyze customer purchasing patterns
- Study discount and promo code usage
- Understand customer demographics
- Identify spending trends and shopping preferences

## Tools & Technologies

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. SQL Analysis
5. Database Integration with PostgreSQL
6. Power BI Dashboard Creation
7. Business Insights Generation

## Files

- customer_shopping_behavior.csv
- customer_shopping_behavior.ipynb
- Customer_Shopping_Dashboard.pbix
- SQL_Queries.sql

## Key Insights

- Customer spending patterns were analyzed.
- Discount and promo code usage were evaluated.
- Customer demographics and purchase behavior were explored.
- Interactive Power BI dashboard was created for visualization.
